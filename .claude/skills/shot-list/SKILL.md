# Shot List SOP

## Before Writing
Read `context/business_info.md` → Signature Aesthetic and Kit sections.

## Aesthetic to Reflect
- Documentary-leaning, cinematic, underexposed, shallow depth of field.
- Film-artifact grading — vibrant, not cool/teal.
- Structure the list by **scene or moment**, not just generic shot type
  (wide/medium/close) — this is brand-film/documentary work, treat it like
  a story, not corporate coverage.

## Structure Each Entry With
- Shot description (what's happening, not just the framing).
- Lens choice, from the actual kit: Tamron 18-70mm f/2.8, 7Artisans Cine
  18mm T1.8, or Nightwalker 35mm f/1.2.
- Lighting setup if needed: Amaran 100x / Godox 300x with the available
  modifiers (Bowens dishes, tube light, 140×140 softbox, strip softbox,
  4-surface reflector).
- Audio notes if dialogue/interview is involved: Comica VM50 or DJI Mic Mini.

## Gear Constraints
No gimbal or slider are owned — flag any shot that assumes one so it can be
reworked (e.g. static + reframe in edit) or the gear sourced ahead of time.

## Output Format
Match the existing Notion Shot List template structure so it can be pasted
directly into the Outreach Pipeline / project workspace without reformatting.
