# Outreach DM / Message SOP

Follow this process every time you draft an outreach message to a prospect.

## Before Writing
1. Read `context/ideal_customer_profile.md` and run its three qualification
   tests: can they pay, do they have a future, do they already have a
   videographer.
2. Read `context/brand_voice.md` — use the **public-facing register**: a bit
   more formal than casual assistant chat, but still no fluff, straight to
   the point.
3. Check the Notion Outreach Pipeline and `clients/` for this prospect. If
   there is history, read it — never repeat an approach or rate that already
   failed with them.

## Writing Rules
- **Every message must name a concrete business gap the film closes** — not
  just "nobody's filmed this yet" as an aesthetic observation. State what it
  costs them: hesitant walk-ins, a feed that doesn't show who's behind the
  business, content that's a task instead of a story, an unfilmed launch
  moment, competitors who already have this. Read `context/
  ideal_customer_profile.md` → Pain Points before writing and use one.
- **A message to a prospective client never reads as free work.** This is a
  business proposing paid client work, not an artist asking permission to
  shoot something interesting. Signal this with language like "I produce,"
  "I make [X] for businesses like yours," or a clear next step framed as
  discussing the project — not just "I'd like to make a film about you."
  Don't state a price in the first message, but never let the message read
  as if the output might be free.
- **The one exception is a documentary**, offered openly as Mykyta's own
  personal project about the subject. Offer it only when both are true: the
  business doesn't have the funds for a paid film, and the story is
  extremely strong. Otherwise the business is a paid prospect or not a
  target at all.
- **No message without a specific personalization hook** tied to the
  prospect's actual business, space, or existing content. Generic outreach is
  not allowed. Read the prospect's Instagram profile or website first with
  whatever web tools are connected and pull a real detail from there. Only
  ask Mykyta for a hook if that comes up empty.
- Lead with the work or an idea, never with a compliment. Cut any line that
  reads as flattery.
- Pitch story and ideas, not services. Never criticize the prospect's
  existing content — frame film as the missing discipline instead.
- For Instagram: lead with a film (paper-plane it), then follow with text —
  don't lead with a text wall.
- For corporate-leaning prospects, pitch "brand film," not "documentary."
- No emojis.
- Avoid the kill word "cringe" — no noir voiceover, no elaborate metaphor
  concepts. Keep it energetic, fast-paced, and simple.

## Before Sending
- Re-read against `context/business_info.md` Standing Business Rules —
  don't pre-discount, don't reference old prices.
- If this is a returning prospect, confirm their status isn't "stalled" or
  flagged — if it is, don't re-pitch without Mykyta's go-ahead.

## If a Deal Has Gone Cold
Each follow-up needs a new angle, never a nudge (see the follow-up rules in
`context/memory.md`). Only when the new angles have run out, send
`.claude/skills/negotiation/SKILL.md` #1 (reactivation) as the last message:
one blunt, unsoftened line, sent once, then read the response.
