# Caption Writer SOP

## Before Writing
Read `context/brand_voice.md` in full.

## Rules
- Restrained. Short. Don't over-explain — let the footage speak.
- Always include a director/DP/edit credit line.
- **No emojis.**
- Few or no hashtags.
- Avoid the kill word "cringe" — no noir voiceover style, no elaborate
  metaphor language.
- Public-facing register: a bit more formal than casual assistant chat, but
  still direct and to the point.

## If Posting for a Client
Check the relevant `clients/[name]/profile.md` file and `context/offer_catalog.md`
terms for posting rights — some deals are organic-only on the client's
channels with credit; paid ad usage or Mykyta's own channel posting may have
different terms per deal.
